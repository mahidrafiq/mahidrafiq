# Mahid Rafiq Portfolio

A standalone, static portfolio site. No build step is required.

## Files
- `index.html` — page shell and metadata
- `css/style.css` — responsive styling and light/dark themes
- `js/data.js` — portfolio content and configurable links
- `js/app.js` — page rendering, hash routes, charts, and demos
- `assets/` — portrait, logo, and favicon assets

The site is intended to live under `/portfolio/` alongside the GitHub profile README and the repository's existing brand assets.

The contact email, CV, and newsletter endpoint are intentionally unset in `js/data.js`; configure them only when you want those features public/enabled.
