# Mahid Rafiq — Brand Assets

This folder contains reusable logo masters and visual identity guidance for Mahid Rafiq.

## Folders

- [svg/](svg/) — scalable logo artwork; preferred for websites and design tools.
- [png/](png/) — reserved for raster exports such as social avatars and app icons.
- [icons/](icons/) — favicons and small-size icon assets.
- [guidelines/](guidelines/) — colour palette and usage rules.
- [previews/](previews/) — identity boards and contact sheets.
