# Mahid Rafiq — Brand Assets

**Brand line: Engineer the Essential**

This folder contains the core SVG logo masters, selected small PNG exports, and visual identity guidance for Mahid Rafiq. The identity uses the monochrome MR orbital mark and Midnight Voltage palette.

## Folders

- [svg/](svg/) — scalable logo variants and masters.
- [png/](png/) — selected small raster exports currently mirrored in the repository, including favicons and 64 px app icons.
- [icons/](icons/) — favicon usage notes.
- [guidelines/](guidelines/) — colour palette, typography, and logo usage rules.
- [preview/](preview/) — notes for brand-board previews.
- [motion/](motion/) — notes for animated logo assets.
