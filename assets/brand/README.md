# Mahid Rafiq — Brand Asset Kit

**Brand line: Engineer the Essential**

A technology-forward personal identity built around the monochrome MR orbital mark and the Midnight Voltage palette. The tagline expresses a builder's mindset while leaving room for software, AI, automation, science, health technology, and future ventures.

## Included assets

- `svg/` — scalable, editable logo variants and masters.
- `png/` — ready-to-use raster exports, social avatars, app icons, favicon sizes, and emblem variants.
- `guidelines/` — palette, typography, and logo-use notes.
- `preview/brand_asset_variants_board.png` — contact sheet of the revised brand assets.
- `motion/` — animated logo ad, preview GIF, and poster frame.

## Core lockups

- **Primary horizontal** — portfolio header, LinkedIn banners, documents, and presentations.
- **Primary stacked** — square/social compositions and cover art.
- **Lettermark / app icon** — GitHub avatar, social avatar, and app icon.
- **Wordmark** — text-only placements when the monogram would be redundant.
- **Emblem** — occasional special applications, not the default logo.
- **Favicon** — simplified initials for 16–32 px use.

## Recommended use

1. Use the horizontal combination mark as the main portfolio signature.
2. Use the monochrome MR orbital icon for GitHub and social avatars.
3. Use Voltage Lime in small details and interface highlights; do not recolour every logo element.
4. Choose dark or light logo variants according to background contrast.
5. Use the simplified favicon at 16–32 px; the full orbital detail is too fine at very small sizes.
6. Prefer SVG masters for web and scalable work. For print, use one-colour artwork and verify minimum stroke reproduction with the print vendor.

Do not stretch, rotate, add effects to, or place a low-contrast logo on its background. The tagline is **Engineer the Essential**; logo lockups use it without a full stop for a cleaner visual finish.
