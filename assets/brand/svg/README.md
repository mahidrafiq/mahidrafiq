# SVG Logo Masters

Editable, scalable logo artwork for web projects and design tools.

- `primary_horizontal_dark.svg` — default horizontal lockup on a dark background.
- `primary_horizontal_light.svg` — dark lockup on a light background.
- `primary_stacked_dark.svg` / `primary_stacked_light.svg` — centered stacked lockups.
- `primary_horizontal_transparent_darktext.svg` / `primary_horizontal_transparent_whitetext.svg` — transparent-background versions.
- `lettermark_black.svg`, `lettermark_white.svg`, `lettermark_silver.svg`, `lettermark_lime.svg` — monogram variants.
- `app_icon_dark.svg`, `app_icon_light.svg`, `app_icon_forest.svg` — square icon variants.
- `wordmark_dark.svg`, `wordmark_light.svg`, `wordmark_name_only.svg` — wordmark variants.
- `symbol_orbit_*.svg` — standalone orbital motif.
- `emblem_dark.svg` / `emblem_light.svg` — badge-style variants.
- `print_one_color_*.svg` / `print_mark_lime.svg` — simplified print marks.

The master brand line is **Engineer the Essential**. SVGs use uppercase display text in lockups. Prefer these vector masters over cropping a presentation board.
